
# UI-UX-Experiment3

## Aim:

To perform a heuristic evaluation of 2–3 competing websites/apps, compare their user experience, identify usability issues, and suggest improvements.

## Algorithm:
1.Select 2–3 competing websites/apps.

2.Evaluate them using Nielsen’s Heuristic Principles.

3.Compare their UX features and usability.

4.Identify strengths and weaknesses.

5.Suggest required design improvements.

6.Incorporate the proposed changes into the design.

7.Review the improved user experience.

## Output:
[UI exp-3.pdf](https://github.com/user-attachments/files/28016140/UI.exp-3.pdf)

## Result:
The selected websites/apps were analyzed and compared using heuristic evaluation. Usability issues were identified, improvements were proposed, and the enhanced design provided a better user experience and usability.
